# Healthcare & Life Expectancy Data Analysis

Exploratory data analysis on healthcare spending vs life expectancy 
across 6 countries (1970-2020) using Python, Pandas, Matplotlib and Seaborn.

## Key Findings
- USA spends the most on healthcare but doesn't have the highest life expectancy
- Japan has the highest life expectancy despite lower spending than USA
- All countries show steady increase in life expectancy from 1970 to 2020
- COVID-19 impact visible as dip in USA life expectancy in 2020

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
